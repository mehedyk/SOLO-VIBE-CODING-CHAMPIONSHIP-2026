# Prompts for other AIs — logo, icon, favicon, banners

Brand: **Primary Visual Lab / প্রাইমারি ভিজ্যুয়াল ল্যাব**. Palette: deep navy `#0f2a43`, forest green `#14532d`, amber `#fbbf24`, mint `#34d399`, white. Feeling: warm, trustworthy classroom tool, not cartoonish, not corporate-cold.
Tell every AI: **no text baked into raster images unless stated, no stock mascots, no copyrighted characters, flat vector style, high contrast, must stay readable at small size.**

## 1. Logo (vector, SVG preferred)
> Design a flat vector logo mark for "Primary Visual Lab", a classroom maths visualiser for primary school. Concept: ten small amber squares merging into one tall mint bar (ten ones exchanging into one ten). Rounded corners, 3 colours maximum from #0f2a43, #34d399, #fbbf24 on transparent background. Provide: mark only, and mark + wordmark horizontally, wordmark "Primary Visual Lab" in a friendly geometric sans. Output clean SVG with no gradients, no filters, no embedded raster. Also provide a one-colour (white) and one-colour (navy) version.

## 2. Bangla wordmark
> Create a horizontal lockup of the Bangla text "প্রাইমারি ভিজ্যুয়াল ল্যাব" beside the logo mark described above. Use correct Bangla conjuncts (প্র, ভ, জ্যু). Do not alter letter shapes. Match weight to the Latin wordmark. Export SVG with text converted to outlines.

## 3. App icon / favicon set
> Take the logo mark only and make it fit a square with 12% padding. Deliver a rounded-square version on navy #0f2a43. Export: `favicon.svg`, `favicon.ico` (16, 32, 48 px), `apple-touch-icon.png` 180×180, `icon-192.png`, `icon-512.png`, and a maskable 512×512 icon with the mark inside the central 80% safe zone. Must stay legible at 16 px: simplify to 3 amber squares + 1 mint bar if needed.

## 4. GitHub README banner (animated SVG or GIF)
> Make a 1280×320 banner. Left: the logo mark and the title "Primary Visual Lab". Right: a looping 6-second animation where ten amber squares slide together, fade, and become one mint bar, with the caption "10 ones = 1 ten" appearing. Keep the file under 300 KB. Provide an SVG (SMIL) version and a GIF fallback. Dark navy background, respects `prefers-reduced-motion` in the SVG.

## 5. Social/OG image
> 1200×630 static image: navy background, mark at left, the sentence "See how numbers change" in large type, a small row of blocks showing 52 − 27 with one exchange arrow. No photos of children.

## 6. Section divider / animated GitHub dividers
> Create a 900×24 animated SVG divider: a thin amber line with a small block sliding left to right and back, 4s loop, subtle.

## 7. Bangla splash / loading illustration
> Flat vector illustration of a teacher's hand pointing at a projected screen showing blocks. No faces. Palette above. Transparent background. 800×600.

Always review AI-made art for: wrong Bangla letters, stray text, copied marks (reverse-image-search the logo), and licence terms.
